### Google Image Scraper

Downloads high-resolution images from Google Images based on a search query and desired number of images.

#### Technologies Used
- Python  
- Selenium  
- BeautifulSoup  
- Requests

#### Setup
1. Download the ChromeDriver matching your Chrome version from [ChromeDriver downloads](https://googlechromelabs.github.io/chrome-for-testing/#stable).  
   Update the path in `example_config.json`.

2. Install dependencies:
```bash
pip install -r requirements.txt
```
